# SimpanSikit

Personal finance web app (PWA) for iPhone, themed as the Moon Ledger from the novel *New Earth Online: Wrong Server Lord* by dizzypapaya.

- Open on iPhone in Safari, then Share > Add to Home Screen.
- All data stays on the phone (browser storage). Use Council > Backup to export a ledger copy to Files or iCloud Drive.
- This repo holds only the app code. No financial data is stored here.

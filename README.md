# SimpanSikit

Personal finance web app (PWA) for iPhone, focused on clearing debt. Plain interface: Home, Records, Debts, Accounts, Settings.

- Open on iPhone in Safari, then Share > Add to Home Screen.
- All data stays on the phone (browser storage). Use Settings > Backup to export a ledger copy to Files or iCloud Drive.
- This repo holds only the app code. No financial data is stored here.

The game version (until Nov 2026) is in git history. It used the same storage key, so data carries over. The sprites folder is no longer used by the app.
